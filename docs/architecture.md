# Архитектура инженерного контура

## 1. Сетевая топология и изоляция (Zero Exposed Backend Ports)

Весь трафик локальной сети централизованно поступает на реверс-прокси:

```text
            [ Локальная сеть / Браузер ]
                         │
                 (Порты 80 / 443)
                         ▼
┌────────────────────────────────────────────────────────┐
│ Nginx Proxy Manager (Единый Ingress-шлюз)              │
└────────────────────────────────────────────────────────┘
                        │
     [ Внутренняя bridge-сеть Docker: proxy-net ]
                        │
    ┌────────────────┬──┴─────────────┬───────────────┐
    ▼                ▼                ▼               ▼
[ Dashy ]     [ Vaultwarden ]    [ Grafana ]    [ DokuWiki ]
    │                                 │
[ IT-Tools ]                    [ Prometheus ]
    │                                 │
[ CyberChef ]                  [ Node Exporter ]

```
## 2. Модель наблюдаемости (Observability)
**Node Exporter** монтирует системные каталоги /proc/, /sys/ хоста в режиме read-only и собирает системные метрики ядра Debian.

**Prometheus** по внутреннему интервалу 15 секунд опрашивает endpoint http://node-exporter:9100/metrics.

**Grafana** использует внутренний DNS Docker (http://prometheus:9090) и визуализирует графики нагрузки без выставления базы метрик наружу.
