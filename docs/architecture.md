# Архитектура инженерного контура

## 1. Сетевая топология и изоляция (Zero Exposed Backend Ports)

Весь трафик локальной сети централизованно поступает на реверс-прокси:

\\\	ext
[ Локальная сеть / Браузер ]
            │
     (Порты 80 / 443)
            ▼
┌────────────────────────────────────────────────────────┐
│ Nginx Proxy Manager (Единый Ingress-шлюз)              │
└────────────────────────────────────────────────────────┘
            │
  [ Внутренняя bridge-сеть Docker: proxy-net ]
            │
   ┌────────┴────────┬────────────────┬───────────────┐
   ▼                 ▼                ▼               ▼
[ Dashy ]     [ Vaultwarden ]    [ Grafana ]    [ DokuWiki ]
   │                                  │
[ IT-Tools ]                    [ Prometheus ]
   │                                  │
[ CyberChef ]                  [ Node Exporter ]
\\\

## 2. Модель наблюдаемости (Observability)
1. **Node Exporter** монтирует системные каталоги \/proc\, \/sys\ хоста в режиме \ead-only\ и собирает системные метрики ядра Debian.
2. **Prometheus** по внутреннему интервалу 15 секунд опрашивает endpoint \http://node-exporter:9100/metrics\.
3. **Grafana** использует внутренний DNS Docker (\http://prometheus:9090\) и визуализирует графики нагрузки без выставления базы метрик наружу.
